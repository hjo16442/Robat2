# ربات ۲ (Robat2)

ربات ۲ یک دستیار برنامه‌نویسی هوش مصنوعی است. از داخل اپ اندروید، درخواستت را با زبان عادی می‌نویسی؛ موتور Gemini ساختار پروژه را بررسی می‌کند، تغییرات لازم را در چند فایل پیاده‌سازی می‌کند و پس از اجرای تست‌ها، تغییرات موفق را روی شاخه همان Pull Request ثبت می‌کند.

## قابلیت‌ها
- دریافت درخواست طبیعی فارسی یا انگلیسی، نه فقط فرمان ثابت.
- پیاده‌سازی قابلیت جدید، اصلاح خطا، بازطراحی رابط، بازآرایی و بهبود عملکرد.
- بررسی هم‌زمان مجموعه‌ای از فایل‌های متنی پروژه و تغییر چند فایل مرتبط.
- حفظ امکانات قبلی و هماهنگی با معماری و زبان پروژه.
- اجرای تست Maven یا Gradle پیش از commit و push.
- جلوگیری از اصلاح PRهای Fork و مسیرهای خارج از مخزن.
- عدم ادغام خودکار PR؛ بازبینی نهایی با کاربر است.

## راه‌اندازی موتور هوش مصنوعی
در GitHub وارد مسیر زیر شوید:
**Settings → Secrets and variables → Actions → New repository secret**

یک Secret با نام دقیق زیر بسازید:
- `GEMINI_API_KEY`: کلید API از Google AI Studio.

اختیاری:
- `GEMINI_MODEL`: شناسه مدل Gemini؛ مقدار پیش‌فرض `gemini-3.8-flash` است.

بدون `GEMINI_API_KEY)، درخواست از اپ ارسال می‌شود اما پیاده‌سازی هوش مصنوعی انجام نخواهد شد. کلید را در اپ یا پیام عمومی قرار ندهید.

## مجوزهای GitHub Actions
در **Settings → Actions → General → Workflow permissions** گزینه **Read and write permissions** را فعال کنید تا workflow بتواند commit و push را روی شاخه PR انجام دهد.

## استفاده از اپ اندروید
1. یک GitHub Personal Access Token با مجوز **Issues: Read and write** برای مخزن بسازید.
2. نام مخزن را به شکل `owner/repository` وارد کنید.
3. شماره Pull Request و توکن را وارد کنید.
4. در کادر درخواست، دقیقاً بنویسید چه قابلیتی می‌خواهید یا چه چیزی باید اصلاح شود.
5. «اجرای درخواست و پیاده‌سازی در کد» را بزنید.
6. نتیجه و گزارش تست را در GitHub Actions و گفت‌وگوی PR ببینید.

نمونه درخواست:
- «قابلیت ورود با اثر انگشت اضافه کن.»
- «صفحه اصلی را فارسی و حرفه‌ای طراحی کن.»
- «خطای ذخیره اطلاعات را پیدا و برطرف کن.»
- «سرعت اجرای برنامه را افزایش بده، بدون حذف قابلیت‌های فعلی.»

توکن GitHub فقط برای همان درخواست در حافظه اپ استفاده می‌شود و ذخیره نمی‌شود. توکن یا کلید Gemini را برای دیگران ارسال نکنید.

## محدودیت‌ها و حفاظت‌ها
- موتور فقط فایل‌های متنی مجاز پروژه را در محدوده اندازه و تعداد مشخص بررسی می‌کند؛ فایل‌های باینری، secrets، کلیدها، فایل‌های امضای برنامه، wrapperهای ساخت و workflowهای CI را تغییر نمی‌دهد.
- فایل جدید فقط در صورت داشتن مسیر مجاز و داخل مخزن قابل ایجاد است؛ حذف فایل انجام نمی‌شود.
- PRهای Fork رد می‌شوند.
- اگر تست شناخته‌شده پروژه وجود نداشته باشد یا شکست بخورد، هیچ commit/push انجام نمی‌شود.
- پاسخ هوش مصنوعی ممکن است خطا داشته باشد؛ قبل از Merge، diff و نتیجه تست را بررسی کنید.
- پردازش هوش مصنوعی روی GitHub Actions انجام می‌شود، نه روی خود گوشی.

## ساخت APK
از GitHub Actions، workflow با نام **Build Android APK** را اجرا کنید. پس از موفقیت، artifact با نام `Robat2-Android-APK` در همان اجرای workflow قابل دریافت است.
